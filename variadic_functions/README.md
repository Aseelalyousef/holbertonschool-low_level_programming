# C - Variadic functions

This project covers what variadic functions are in C, how to use `va_start`, `va_arg`, and `va_end` macros, and why and how to use the `const` type qualifier.

## Files
* `variadic_functions.h` - Header file containing all function prototypes.
* `0-sum_them_all.c` - Function that returns the sum of all its parameters.
* `1-print_numbers.c` - Function that prints numbers, followed by a new line.
* `2-print_strings.c` - Function that prints strings, followed by a new line.
* `3-print_all.c` - Function that prints anything based on a format string.
